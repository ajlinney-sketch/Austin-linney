# HomeField Wilco — Monday Team Reset

Static single-page leadership presentation for the HomeField Williamson County team reset on September 28, 2026.

## Deploy on Netlify

This repository is deployment-ready.

- Build command: none
- Publish directory: `.`
- Entry file: `index.html`
- Netlify configuration: `netlify.toml`

Connect this repository to Netlify and deploy. No package install, framework, environment variable, or build step is required.

## Local preview

Open `index.html` in any modern browser.

## Content

The page presents:
- current business reality and 12-month goals
- operating priorities and meeting agenda
- customer reputation / review highlights
- role ownership and handoffs
- team incentive program
- operating ground rules
- roadblock ownership capture
- closing commitments
